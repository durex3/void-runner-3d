# 遗迹工坊 · 第三关开发进度

## 当前目标

第三关「风蚀哨站」先完成可玩的垂直切片：风道教学 → 组合遭遇 → Clanker Boss。保持第一、二关规则兼容，不引入跨局成长。

## 设计契约

- 玩家承诺：在荒废哨站中读懂风向、改变路线并抓住机械守卫收招。
- 核心循环：移动/攻击 → 观察风道预警 → 离开或利用安全区 → 击败波次 → 在 Boss 收招反击。
- 失败原因必须可读：风道把人推向边界、Boss 扇击或接触伤害。
- 非目标：本轮不做随机房间、跨关继承、新职业或永久天赋。
