# 遗迹工坊 · Relic Workshop

独立 Three.js 浏览器 3D 肉鸽小游戏。所有运行内容均在当前目录，完整规则和数值见 [玩法与属性说明](./玩法与属性说明.md)。

文档同步日期：2026-09-21。其他说明：[项目架构](./ARCHITECTURE.md) · [武器素材清单](./武器素材清单.md) · [素材方案与后续计划](./素材方案.md) · [美术来源与许可](./ART-CREDITS.md) · [特效接入验收](./特效接入验收.md) · [资源候选清单](./资源候选清单.md)。

项目进度与后续安排见 [开发计划](./开发计划.md)，包含已实现功能、当前限制和各阶段验收标准。

## 运行

开发服务启动后访问 http://127.0.0.1:5188/ 。双击 `START-GAME.cmd`，或执行 `npm install`、`npm run dev`；需要 Node.js 20.19+。

`npm run build` 生成 `dist/`，通过 HTTP 静态服务器托管，不要直接双击 HTML。

## 角色与操作

标题页可选择第一关「遗迹工坊」或第二关「熔炉要塞」。第二关已接入独立地牢场景、八波组合、地火预警、突击兵冲锋与黑骑士 Boss。第一关胜利也可进入第二关，但会重置生命、升级和装置，当前不是跨关继承构筑的战役模式。两关分别记录最佳击败数。详见 [第二关验收](./第二关验收.md)。

单独测试 Boss：打开 http://127.0.0.1:5188/boss-test.html ，默认黑骑士＋骑士钉锤、1.6 倍攻速。设置可选两关 Boss、四职业武器、伤害/攻速、满血/49% 生命及玩家无敌，点击「应用设置并重开」生效。点击面板标题可收起遮挡；WASD 移动、空格冲刺、1/2/3 换武器。无小怪、装置和升级，不写正式通关纪录；此入口也包含在生产构建中。用 `npm run test:boss-page` 回归页面流程。

WASD / 方向键移动，空格冲刺，自动瞄准攻击，1/2/3 或武器栏切换当前角色装备，Esc 暂停，切出窗口自动暂停。工程师只有两个槽位。触屏提供方向与冲刺按钮。

| 角色 | 武器池 | 玩法 |
|---|---|---|
| 骑士 | 剑盾、双手剑、钉锤 | 持盾减伤、范围击退、短程硬直 |
| 游侠 | 复合弩、长弓、轻便手弩 | 稳定单发、穿透三敌、手持移速 +12% |
| 工程师 | 霰弹枪、速射手弩 | 近距散射击退、三连发 |
| 德鲁伊 | 德鲁伊法杖、雷鸣法杖、魔杖 | 延迟范围减速、逐敌连锁、飞行魔弹溅射 |

共 11 套配置，使用 10 个不同武器模型及圆盾。开局选择角色；重开保留角色和装备，结算可更换角色。基础生命、移速相同，装备机制不同。

换武器不刷新冷却，取消未发出的连射箭和未完成前摇的近战；已经射出的弹丸、已经施放的自然冲击保留。暂停冻结延迟攻击，重开清理旧攻击。

## 战利品与局内成长

- 武器击杀掉落经验与装置资源：60% 同系资源，其他两系各 20%。弓弩/近战偏弩台、霰弹偏炸瓶、法术偏法典。
- 靠近资源自动部署，1.1 秒启动，存在 48 秒，最多 24 件。三类装置分别远程单体、近敌爆炸、范围电击。使用包内实际道具模型，无种植设定。
- 经验升级选择属性或装置联动升级。升级卡会明确标注“装置联动 / 核心属性 / 生存强化”等类型，并根据当前职业优先推荐合适联动；三种装置对应六种联动规则，并非六种装置。“火力超载”依赖霰弹，仅进入工程师升级池。联动首次触发会显示一次性战斗提示，结算显示本局触发次数。获取、部署与各项触发条件详见 [玩法与属性说明第 6、7 节](./玩法与属性说明.md)。
- 第 2/4/6 波精英残血后可收服构装伙伴或换一次升级；伙伴负责采集或治疗/维护。
- 每关共八波。第一关骸骨巨像交替使用环形弹幕、预判扇射和践踏，践踏结算后有 2.2 秒恢复期。第二关黑骑士采用锁定冲锋、扇形重斩与地火召唤，半血后启用两连斩和对向双炉；重斩收招 1.8 秒，冲锋/地火收招 2.4 秒。清空第八波获胜，每波间恢复 12 生命。

## 素材与动作

采用用户提供的 KayKit Adventurers 2.0 EXTRA、Skeletons 1.1 EXTRA 与 Character Animations 1.1。基础骨骼走跑、受击、死亡已接入；骑士使用官方单手挥砍、双手下劈、持盾和格挡受击动作。近战上半身动作与下半身走跑分层，避免攻击时双腿停止运动。现有远程角色仍为程序辅助握持与射击姿态，完整远程动作暂未替换。

场景为程序化遗迹，边界实例化绘制，搭配 Kenney CC0 树岩。骑士三种近战使用 Kenney Particle Pack 的精选贴图，分别表现快速斩击、重斩扬尘和钉锤冲击；真实命中还会触发武器专属音色、局部打击停顿、受击动作与分级镜头冲击。角色共享几何体/贴图、独立骨骼；死亡实例 1.6 秒清理。像素比上限 1.6，装置 24、战利品 36、玩家弹丸 160、粒子/临时线 180。来源与许可见 `ART-CREDITS.md`。

武器反馈已进一步细化：游侠使用实体箭模型，长弓配金色拖尾、箭尖亮点和命中碎光；德鲁伊法杖以种子与叶簇传递到固定落点，再展开根须和叶片。骑士重剑从真实剑刃位置采样挥砍拖尾，补充面向镜头的剑尖亮边，修复左下等斜向不可见的问题。工程师使用序列帧弹体，雷鸣法杖与聚能魔杖保留各自连锁和魔弹表现。上述调整不改变伤害、攻速或判定范围；远程专属音色、混战性能与整局平衡仍待完善。

## 验证

- `npm run test:readability`：固定混战、敌方远程前摇和 Boss 预警回归，含四角色桌面/手机截图、躲避、暂停、死亡取消践踏及窄屏布局。测试入口与验证边界见 [战斗可读性测试](./战斗可读性测试.md)。
- `npm test`：54 项机制测试，以及第一关浏览器移动、属性/装置面板、升级、精英选择、死亡重开、八波通关分支、手机布局。
- `npm run test:feedback`：装置箭迹、电弧、爆炸及钉锤抵抗反馈，验证伤害不变、普通敌人眩晕、暂停/清理和桌面/手机画面。
- `npm run test:level2`：地火与方向判定单测，以及第二关关卡选择、四职业加速流程、黑骑士攻击/收招、冻结、清理、桌面/手机像素和截图验证。
- `npm run test:weapons`：11 套配置的伤害/间隔/握持、暂停/切换/重开、骑士真实动作/盾牌减伤/钉锤打断、命中手感参数，以及三种近战特效的时序、贴图、桌面和移动端画布验证。
- `node tests/kaykit.mjs`：角色切换、贴图、独立骨骼、基础动作与清理。
- `node tests/heavy-sword-visual.mjs`：桌面与手机端各八方向，验证重剑挥砍窗口、实际渲染像素、命中时序和切换清理。
- `node tests/ranger-nature-visual.mjs`：游侠与自然法杖的飞行、命中、画布像素和资源回收。
- `node tests/assets-visual.mjs` / `node tests/beam-directions.mjs`：全武器资源截图与八方向闪电连接端点检查。专项脚本需单独执行，不包含在 `npm test` 中。

回归脚本使用本机 Edge + Playwright，开发服务需运行在 5188；交互和视觉复核优先使用 Google Chrome DevTools。截图、录像和 JSON 在 `test-results/`。调试接口只在 `?test=1` 存在；通关测试加速清怪验证逻辑，不等于完成整局难度评估。

2026-09-21 第一关实测记录：四职业首轮八波均已通关，游侠 151 秒、德鲁伊 180 秒、工程师 166 秒、骑士 174 秒。远程需要走位但很少受伤；骑士能利用 Boss 收招反击，受伤主要来自主动挤进小怪群。第一关首轮初步验收通过，暂保留当前数值；完整记录与验证边界见 [战斗可读性测试](./战斗可读性测试.md)。每职业仅一局，不代表全部武器、构筑或多局平衡验收完成。第二关现已完成首版实现与自动回归，四职业正常速度实战验收仍待进行。
