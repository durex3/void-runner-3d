## 运行

开发服务启动后访问 http://127.0.0.1:5188/ 。双击 `START-GAME.cmd`，或执行 `npm install`、`npm run dev`；需要 Node.js 20.19+。

局域网手机测试执行 `npm run dev -- --host 0.0.0.0 --port 5188`，手机与电脑连接同一网络后访问 `http://<电脑局域网 IP>:5188/`。当前开发机示例地址为 `http://192.168.4.2:5188/`，IP 变化时以系统网络信息为准。

`npm run build` 生成 `dist/`，通过 HTTP 静态服务器托管，不要直接双击 HTML。

构筑平衡分析页：<http://127.0.0.1:5188/balance-report.html>。从正式游戏结算页下载多个 JSON 后导入，可按角色和关卡比较武器/装置输出、角色胜率、Boss 战时间、联动触发和掉血来源。新报告带单局 `runId`，旧版报告使用稳定内容指纹；报告库使用当前浏览器 `localStorage` 持久化并去重。每局可写备注或单独删除，也可导出/恢复完整数据集。当前筛选不足 3 局时只提示样本不足，不输出异常平衡结论。分析不上传数据，也不修改战斗规则。

移动端性能压测打开 `http://127.0.0.1:5188/performance-test.html`。页面独立于正式首页，提供普通战斗、满装置、敌弹与地火、Boss 叠加和极限压力五档预设，记录 FPS、帧时间、Draw Calls、三角形、纹理、活动对象和 WebGL renderer。局域网手机可将地址中的主机替换为电脑 IP；也可使用 `?preset=extreme` 直接加载极限场景。压测结果用于定位瓶颈，不等同于正式关卡难度验收。

触屏设备的正式游戏启用自适应像素比：持续帧时间高于约 20.5 ms 时逐级下调 DPR，最低 1.25；连续稳定后逐步恢复到设备 DPR 上限 1.6。性能页的 15 秒采样结束后会冻结最终快照，避免实时数据继续变化。装置电击轨迹使用单次折线绘制，移动端高特效密度下减少普通受击碎光；伤害和攻击判定不变。

## 角色与操作

标题页可选择第一关「遗迹工坊」、第二关「熔炉要塞」或第三关「风蚀哨站」。第二关已接入独立地牢场景、八波组合、地火预警、突击兵冲锋与黑骑士 Boss；第三关采用四波灰盒流程、风道和反制收招。第一关胜利也可进入第二关，第二关胜利可进入第三关，但会重置生命、升级和装置，当前不是跨关继承构筑的战役模式。三关分别记录最佳击败数。详见 [第二关验收](./第二关验收.md) 与 [第三关开发方案](./第三关开发方案.md)。

单独测试 Boss：打开 http://127.0.0.1:5188/boss-test.html ，默认黑骑士＋骑士钉锤、1.6 倍攻速。设置可选两关 Boss、四职业武器、伤害/攻速、满血/49% 生命及玩家无敌，点击「应用设置并重开」生效。点击面板标题可收起遮挡；WASD 移动、空格冲刺、1/2/3 换武器。无小怪、装置和升级，不写正式通关纪录；此入口也包含在生产构建中。用 `npm run test:boss-page` 回归页面流程。

WASD / 方向键移动，空格冲刺，自动瞄准攻击，1/2/3 或武器栏切换当前角色装备，Esc 暂停，切出窗口自动暂停。工程师只有两个槽位。触屏使用左侧虚拟摇杆控制方向与力度，右侧按钮冲刺；摇杆包含径向死区，松手、取消触摸、失焦或切后台都会归零。

| 角色 | 武器池 | 玩法 |
|---|---|---|
| 骑士 | 剑盾、双手剑、钉锤 | 持盾减伤、范围击退、短程硬直 |
| 游侠 | 复合弩、长弓、轻便手弩 | 稳定单发、穿透三敌、手持移速 +12% |
| 工程师 | 霰弹枪、速射手弩 | 近距散射击退、三连发 |
| 德鲁伊 | 德鲁伊法杖、雷鸣法杖、魔杖 | 延迟范围减速、逐敌连锁、飞行魔弹溅射 |

共 11 套配置，使用 10 个不同武器模型及圆盾。开局选择角色；重开保留角色和装备，结算可更换角色。基础生命、移速相同，装备机制不同。

换武器不刷新冷却，取消未发出的连射箭和未完成前摇的近战；已经射出的弹丸、已经施放的自然冲击保留。暂停冻结延迟攻击，重开清理旧攻击。

## 战利品与局内成长

- 武器击杀掉落经验与装置资源：60% 同系资源，其他两系各 20%。弓弩/近战偏弩台、霰弹偏炸瓶、法术偏法典。
- 靠近资源自动部署，1.1 秒启动，存在 48 秒，最多 24 件。三类装置分别远程单体、近敌爆炸、范围电击。使用包内实际道具模型，无种植设定。
- 经验升级选择属性或装置联动升级。升级卡会明确标注“装置联动 / 核心属性 / 生存强化”等类型，并根据当前职业优先推荐合适联动；三种装置对应六种联动规则，并非六种装置。“火力超载”依赖霰弹，仅进入工程师升级池。联动首次触发会显示一次性战斗提示，结算显示本局触发次数。获取、部署与各项触发条件详见 [玩法与属性说明第 6、7 节](./玩法与属性说明.md)。
- 每局会旁路记录构筑平衡数据：武器持有时间、攻击/命中/实际伤害/击杀，三类装置伤害与击杀，玩家掉血来源，升级选择，联动触发次数和 Boss 战时间。结算页展开“构筑平衡报告”可复制报告或下载 JSON；统计不参与伤害、攻速、掉落、AI 或 Boss 判定。
- 第 2/4/6 波精英残血后可收服构装伙伴或换一次升级；伙伴负责采集或治疗/维护。
- 每关共八波。第一关骸骨巨像交替使用环形弹幕、预判扇射和践踏，践踏结算后有 2.2 秒恢复期。第二关黑骑士采用锁定冲锋、扇形重斩与地火召唤，半血后启用两连斩和对向双炉；重斩收招 1.8 秒，冲锋/地火收招 2.4 秒。清空第八波获胜，每波间恢复 12 生命。
- Boss 反制是三关共享的长期扩展骨架：每个技能分为预警、压缩空间、躲避/反制、短收招；不把后续关卡写成不断增加的 `chapter` 分支。未来可继续接入视线、破盾节点、控制节点、时间窗口和多领域取舍，但不默认使用常驻伤害领域。

## 素材与动作

采用用户提供的 KayKit Adventurers 2.0 EXTRA、Skeletons 1.1 EXTRA 与 Character Animations 1.1。基础骨骼走跑、受击、死亡已接入；骑士使用官方单手挥砍、双手下劈、持盾和格挡受击动作。近战上半身动作与下半身走跑分层，避免攻击时双腿停止运动。现有远程角色仍为程序辅助握持与射击姿态，完整远程动作暂未替换。

场景为程序化遗迹，边界实例化绘制，搭配 Kenney CC0 树岩。骑士三种近战使用 Kenney Particle Pack 的精选贴图，分别表现快速斩击、重斩扬尘和钉锤冲击；真实命中还会触发武器专属音色、局部打击停顿、受击动作与分级镜头冲击。角色共享几何体/贴图、独立骨骼；死亡实例 1.6 秒清理。像素比上限 1.6，装置 24、战利品 36、玩家弹丸 160、粒子/临时线 180。来源与许可见 `ART-CREDITS.md`。

武器反馈已进一步细化：游侠使用实体箭模型，长弓配金色拖尾、箭尖亮点和命中碎光；德鲁伊法杖以种子与叶簇传递到固定落点，再展开根须和叶片。骑士重剑从真实剑刃位置采样挥砍拖尾，剑刃边缘两端渐细、中段略厚，保持淡白色并随真实攻击动画短暂淡出；实际命中仍单独触发闪光、碎片和扬尘。第二关 Boss 地面预警保持危险含义，但降低填充透明度并置于玩家刀光下层，避免遮挡。工程师使用序列帧弹体，雷鸣法杖与聚能魔杖保留各自连锁和魔弹表现。上述调整不改变伤害、攻速或判定范围。

音频使用 Web Audio 总线管理 SFX、UI、Music、Ambience 和 Voice；当前主要为程序化音色。静音即时生效，暂停、恢复、切后台和对象清理会同步音频状态，装置与近战命中加入轻微音高变化以减少重复感。

2026-09-21 第一关实测记录：四职业首轮八波均已通关，游侠 151 秒、德鲁伊 180 秒、工程师 166 秒、骑士 174 秒。远程需要走位但很少受伤；骑士能利用 Boss 收招反击，受伤主要来自主动挤进小怪群。第一关首轮初步验收通过，暂保留当前数值；完整记录与验证边界见 [战斗可读性测试](./战斗可读性测试.md)。每职业仅一局，不代表全部武器、构筑或多局平衡验收完成。第二关现已完成首版实现与自动回归，四职业正常速度实战验收仍待进行。

下一轮真实平衡采集采用“**四职业 × 默认武器固定 × 每职业 3 局**”方案：优先测试第二关「熔炉要塞」，整局不切换武器，正常选择升级和装置，不刻意刷特定联动。共 12 局后再比较通关率、存活时间、总输出、Boss 战时长、承伤、武器/装置贡献和联动触发；第一轮只用于确认职业基础差异，不据单局结果改数值。通过后再进行同职业不同武器的专项测试，每种武器至少 2～3 局并保持整局单武器。
